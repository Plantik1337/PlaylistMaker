<h1 align="center">PlaylistMaker</h1>
<p>Данное приложение использовалось как pet-проект для освоения технологий разработки Android-приложений.
Представляет собой клиент-серверное приложение для поиска музыки (демоверсий) посредством <a href="https://developer.apple.com/documentation/AppleMusicAPI">AppleMusic_api</a></p>

<h2 id="begin">Как использовать</h2>
<ol>
  <li>Системные требования:</li>
  <p><a href="https://developer.android.com/about/versions/10?hl=ru">Android 10 (Level 29 Quince Tart)</a></p>
  <p>20 мегабайт памяти + для сохранения обложек (зависит от размера изображения)</p>
  <p>Доступ в интернет для сетевых операций</p>
  <li>Как получить приложение:</li>
  <p> - Скачать проект из main-репозитория и собрать через Android studio. В данном приложении не используюется token для выполнения сетевого запроса к AppleMusic, поэтому при сборке не должно возникнуть трудностей.</p>
  <p> - Скачать релизную версию приложения <i>(in progress...)</i></p>
</ol>
